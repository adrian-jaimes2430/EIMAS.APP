# EIMAS.APP — Third-Party Notices

## Purpose

This file tracks third-party software, fonts, assets, models, textures, datasets, APIs and other external materials introduced into EIMAS.APP.

The EIMAS.APP proprietary license applies only to original EIMAS.APP materials. It does not override third-party licenses.

## Rule

Before adding an external dependency or asset, record:

| Field | Required |
|---|---|
| Name | Yes |
| Version | Yes, when applicable |
| Source | Yes |
| License | Yes |
| Copyright / creator | When available |
| Commercial use permitted | Yes |
| Attribution required | Yes |
| Redistribution permitted | Yes |
| Modification permitted | Yes |
| Source-code obligations | When applicable |
| Date reviewed | Yes |
| Reviewer / decision | Yes |

## Current inventory

No third-party asset inventory is asserted by this file yet.

Dependencies introduced into `package.json` and lockfiles must be reviewed individually before release.

## Important

A package being available through npm, GitHub, a CDN, an asset marketplace, an AI design tool, or a search result does not by itself establish that its content is commercially reusable.

Do not ship an asset with unclear licensing.

When rights are uncertain:

1. identify the source;
2. inspect its current license;
3. record the license;
4. determine whether commercial use and redistribution are permitted;
5. replace the material or obtain permission if rights remain unclear.

## Fonts

Font licensing must be checked independently from the software license of the application.

## AI-generated or tool-generated material

AI-generated output and design-tool exports must not be assumed to be free of third-party rights or contractual restrictions.

Record the originating tool, relevant terms, source asset references and any applicable restrictions when material is incorporated into the product.

## Updates

This inventory should be updated whenever a dependency or external asset is:

- added;
- upgraded;
- replaced;
- relicensed;
- removed;
- redistributed;
- used in a new distribution channel.
