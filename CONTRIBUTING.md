# Contributing to EIMAS.APP

EIMAS.APP is a proprietary commercial product repository.

## Contribution status

This repository is not currently accepting unrestricted public contributions.

Pull requests or code submissions require explicit authorization from the project maintainer.

## Before changing code

1. Read the relevant architecture documentation.
2. Inspect the current implementation.
3. Make the smallest safe change.
4. Avoid unrelated rewrites.
5. Test the affected behavior.
6. Document important architectural decisions.

## Branches

Preferred pattern:

```text
main
develop
feature/*
```

Use feature branches for meaningful changes.

## Commits

Use clear intent:

```text
feat:
fix:
refactor:
docs:
test:
chore:
```

## Pull requests

A pull request should state:

- What changed
- Why
- How it works
- Testing performed
- Known risks
- Follow-up work

## Intellectual property

Submitting code, designs, documentation, assets or other materials does not automatically grant the submitter any ownership transfer or license to use EIMAS.APP materials.

Any external contribution arrangement must be authorized in writing where legally appropriate.

## Third-party material

Do not submit material unless you have the right to use, modify and distribute it under the intended product terms.

When adding external dependencies or assets, update `THIRD-PARTY-NOTICES.md`.
